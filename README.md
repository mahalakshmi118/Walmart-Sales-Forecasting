# Walmart Sales Forecasting Project

## 📌 Overview
This project analyzes Walmart sales data and builds a forecasting model to predict future sales for stores.

## 📊 Objectives
- Perform EDA on sales data
- Analyze impact of unemployment, CPI, and temperature
- Identify top and worst performing stores
- Detect seasonality trends
- Forecast sales for next 12 weeks

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Statsmodels (SARIMA)

## 📈 Key Insights
- Sales show seasonal trends across weeks
- Some stores consistently outperform others
- External factors like unemployment and CPI have moderate impact

## 🔮 Model
- Used SARIMA model for time series forecasting
- Forecasted next 12 weeks of sales
